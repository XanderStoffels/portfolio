# Portfolio - Vue 3 + Vite + Tailwind CSS + DaisyUI

A modern portfolio website built with Vue 3, Vite, Tailwind CSS, and DaisyUI.

## 🚀 Features

- **Vue 3** - The progressive JavaScript framework with Composition API
- **Vite** - Fast build tool and development server
- **Tailwind CSS** - Utility-first CSS framework
- **DaisyUI** - Beautiful component library for Tailwind CSS

## 🛠️ Development

### Prerequisites

- Node.js (v20 or higher)
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📦 Tech Stack

- **Frontend Framework**: Vue 3 with `<script setup>` syntax
- **Build Tool**: Vite
- **Styling**: Tailwind CSS with DaisyUI components
- **Development**: Hot Module Replacement (HMR)

## 🎨 Tailwind CSS & DaisyUI

This project is configured with:
- Tailwind CSS for utility-first styling
- DaisyUI for pre-built components
- PostCSS with Autoprefixer
- Responsive design utilities
